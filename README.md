# github_practice
# This is to learn about github

# First create a branch on the github website
# Then do git fetch origin <name of the branch>
# Then do git checkout <name of the branch> 
# Use git branch to confirm that you are in your desired branch
# Now make changes to the file and save
# Then do git status 
# Then do git add <name of file that you updated>, but if they are all in the same folder then do git add .
# Then do git commit -m "your message"
# Lastly do git push
# Then go to github and see your change and create a pull request and merge
